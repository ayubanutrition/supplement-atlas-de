# Supplement Atlas DACH

Planungsrepo für eine neue deutschsprachige Supplement- und Nootropika-Vergleichsplattform, getrennt von ayubanutrition.de.

Start: [CLAUDE_MASTER_HANDOFF.md](CLAUDE_MASTER_HANDOFF.md). Aktueller Stand: [docs/STATUS.md](docs/STATUS.md).

## Umsetzung im Browser

1. Claude Code unter https://claude.ai/code öffnen und dieses Repository auswählen.
2. Den START-Prompt aus Abschnitt 13 des Handoffs senden.
3. Claude implementiert und prüft in seiner Cloud-Umgebung auf einem Arbeitsbranch.
4. Nach funktionierendem Build Cloudflare mit dem GitHub-Repo verbinden.

Der Eigentümer benötigt kein lokales Terminal. Standardbudget für neue Ausgaben: 0 EUR.

Dieses Repo enthält zunächst Planung, noch keine Website, recherchierten Produktdaten oder eingerichteten Deployments. Build-Befehle werden nach ihrer tatsächlichen Implementierung dokumentiert.
